# Resource-and-population-dynamics-in-an-agent-environment-interaction-model

[![DOI](https://zenodo.org/badge/1239846877.svg)](https://doi.org/10.5281/zenodo.20211132)

This repository contains the code and images from the paper “Resource and Population Dynamics in an Agent-Environment Interaction Model,” by Briozzo et al., PRE, 2025 (https://doi.org/10.1103/pt8g-kgkr).

Contents:

The repository contains 5 folders for each of the 5 figures in the paper, with the figure number indicated in the folder name. Some of these folders contain subfolders for the different panels of the figure, with the letter of the corresponding panel or panels indicated in the subfolder name.

Each folder or subfolder contains the corresponding figures or panels from the paper, along with a CSV text file containing the metadata in cases of numerical results. In these cases, a ‘code’ folder is also included with the necessary code to perform the simulations and obtain the data.

Each code folder contains three header files: parameters.h, where the simulation parameters are declared; classes.h, where the simulation classes are declared; and functions.h, where the simulation functions are declared. The main program, program.cpp, executes the code and saves the data.
In addition, these folders contain the raw data, along with Python code for plotting and other alternative code.
